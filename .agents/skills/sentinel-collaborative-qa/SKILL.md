# Sentinel Collaborative QA Skill

1. **Git es la verdad**: El historial de git representa evidencia experimental intocable. Nunca hacer rebase, force push ni reset hard.
2. **No hardcodear**: Soluciones dinámicas y exactas.
3. **Verificación Zero-Trust**: Correr pruebas en la terminal y comprobar logs reales antes de dar cualquier tarea por terminada.
4. **Español neutro/chileno**: Mantener tono conciso y técnico.
