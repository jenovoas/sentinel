### 3.2 Data Collection

For each site, we extracted:
1. **Geometric Ratios:** Length/width ratios, angular measurements
2. **Structural Counts:** Number of stones, posts, or geometric elements
3. **Astronomical Alignments:** Documented celestial targets
4. **Base-60 Representation:** Conversion to sexagesimal notation

### 3.3 Statistical Analysis

**Test 1: Chi-Square for Independence**
$$
\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}
$$
Where $O_i$ = observed Base-60 matches, $E_i$ = expected by chance.

**Test 2: Joint Probability**
$$
P_{joint} = \prod_{i=1}^{5} P_i
$$
Assuming independence across sites.

**Significance Threshold:** α = 0.001 (Bonferroni corrected for multiple comparisons)
