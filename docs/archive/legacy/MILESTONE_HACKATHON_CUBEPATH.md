## 🚀 2. La Estrategia Comercial (El Overkill Tecnológico)

Mientras que la base de competidores concursará levantando un VPS normal de mercado, instalando contenedores comunes y haciendo requests a OpenAI o herramientas pre-empaquetadas mediante Dokploy, **Sentinel presentará una anomalía sistémica**:

**El Pitch Técnico de Fénix:**

* Se instalará Sentinel API en el VPS de CubePath, pero vendrá pre-cargado con el **Kernel Modificado por eBPF (El Pentágono de Guardianes)**.
* En lugar de solo mostrar una API de IA estándar devolviendo respuestas (El Requisito Mínimo), se demostrará cómo el propio VPS rechaza ataques de denegación de servicio a 0.0% de CPU y deniega la ejecución de binarios piratas dentro del contenedor.
* La demostración culmina cuando se invoque a la **"TruthSync API"** sobre Axum Rust, mostrando como la Inteligencia Artificial está intrincada y protegida directamente en las raíces del Ring-0.
