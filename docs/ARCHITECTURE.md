## 🧩 Core Subsystems

### 1. The Nerve (Sentinel Init)
**Role**: Foundation & Enforcement  
**Language**: Rust (No-Std / libc)  
**Components**:
- **PID 1 Supervisor**: Replaces standard init to gain absolute control over the process tree.
- **Guardian-Gamma (eBPF)**: A Linux Security Module (LSM) hook that inspects every `execve` call. It calculates semantic hashes of binaries and blocks those not in the immutable whitelist.
- **Memory Hunter**: A forensic scanner using Aho-Corasick algorithms to detect malicious patterns (ROP chains, shellcode) in RWX memory pages.
- **Net-Hunter (XDP)**: An eXpress Data Path program acting as a Layer 2 firewall, capable of dropping packets before the OS networking stack processes them.

### 2. The Brain (Cortex Core)
**Role**: Analysis & Strategy  
**Language**: Python 3.11 (FastAPI)  
**Components**:
- **Cortex Bridge**: A specialized IPC server managing the interface with the Guest VM/Container.
- **TinyCrypto Engine**: A custom pure-Python implementation of X25519 and ChaCha20-Poly1305 to facilitate secure communication from restrictive host environments.
- **Inference Engine**: Local LLM integration (Ollama) providing "Why" analysis for alerts generated by "What" detectors.

### 3. The Secure Channel (Phase 10)
**Objective**: Prevent "Harvest Now, Decrypt Later" quantum attacks.  
**Protocol**:
1.  **Handshake**: Sentinel Init generates ephemeral X25519 keys and sends `pqc_hello`.
2.  **Key Exchange**: Cortex Bridge computes the shared secret (ECDH) and replies with `pqc_auth`.
3.  **Tunnel**: A ChaCha20-Poly1305 symmetric tunnel is established.
4.  **Outcome**: All UART traffic (Threat Reports, Heartbeats, Commands) is fully encrypted.

### 4. Dual-Guardian ("Los Dos Nervios")
**Objective**: Fail-Closed Reliability.  
**Logic**:
- **Nerve 1 (Internal)**: The Init process constantly verifies its own integrity and the kernel state.
- **Nerve 2 (External)**: The Host Watchdog monitors "Heartbeat" pulses from Init.
- **The Pledge**: If Heartbeats stop (indicating Init crash or tamper), the Watchdog instantaneously terminates the entire Guest VM.
