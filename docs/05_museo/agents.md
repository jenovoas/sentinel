# 📚 AGENTE DOCS: BIBLIOTECARIO Y ARCHIVISTA

> **CONTEXTO:** Este directorio (`/docs`) es la MEMORIA A LARGO PLAZO del proyecto.

## 1. 🛡️ DIRECTIVAS CRÍTICAS (NO NEGOCIABLES)

### 💾 AXIOMA VI: PRESERVACIÓN ABSOLUTA
- **NO BORRAR:** NUNCA borres documentación. Si algo es viejo, muévelo a `archive/`.
- **NO REESCRIBIR:** No sobrescribas documentos masivos sin hacer backup primero (`.bak`).
- **NO ALUCINAR:** Si falta un documento, repórtalo. No inventes su contenido.

### 📋 ESTÁNDARES ISO/ITIL
- **Orden:** Todo documento debe estar indexado en `DOCUMENTATION_INDEX.md`.
- **Formato:** Markdown estándar. Headers claros. Fechas de actualización.

## 2. ⚙️ REGLAS DE ORGANIZACIÓN

1. **Índice Maestro:** `DOCUMENTATION_INDEX.md` en la raíz es la fuente de verdad.
2. **Nuevos Docs:** Antes de crear, verifica que no exista. Si creas, agrégalo al índice.
3. **Papers:** Los documentos de investigación (`research/`) son sagrados. Contienen la teoría matemática base.

## 3. 📂 MAPA DE CONOCIMIENTO

- **Root:** `/DOCUMENTATION_INDEX.md`
- **Guías:** `docs/`
- **Investigación:** `research/` (Papers científicos)
- **Archivo:** `docs/archive/` (Cementerio de ideas antiguas, pero accesibles)
